> BucketList.io is a modern, lightweight, multi-language web application designed to help users track, manage, and complete their bucket list goals in a beautifully crafted dark-mode interface.

## ✨ Features

- 🌐 **Internationalization (i18n)**:
  - Automatic browser language detection.
  - Supports **9 languages**: English, Bahasa Indonesia, Español, Français, Deutsch, Русский, 中文, 日本語, and العربية.
  - Full **Right-to-Left (RTL)** layout support for Arabic.
- 🔐 **Client-Side Authentication**:
  - Light user management (Login / Register / Remember Me) powered by `localStorage`.
  - Individual goal list isolation per user account.
- 📊 **Progress & Analytics**:
  - Dynamic progress bar updating completion percentage in real-time.
  - Active goal counters.
- 🎯 **Goal Management**:
  - Add, complete, and delete goals seamlessly with smooth animations.
  - Filter goals by status: **All**, **Active**, or **Completed**.
  - Quick action buttons to **Clear Completed** or **Clear All** goals (with confirmation modal).
- 🎨 **Modern Responsive UI**:
  - Styled with Tailwind CSS and FontAwesome icons.
  - Fully optimized for mobile and desktop screens.

## 🛠️ Tech Stack

- **Markup**: HTML5
- **Styling**: [Tailwind CSS CDN](https://tailwindcss.com) & Custom CSS Animations
- **Icons**: [FontAwesome 6](https://fontawesome.com)
- **Fonts**: [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts
- **Logic**: Vanilla JavaScript (ES6+)
- **Storage**: Browser `localStorage`

## 💻 Getting Started

Since the app is currently built using standard HTML/CSS/JS, you can run it locally without any package managers or build steps!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SanityGuy/bucketlist-io.git
   cd bucketlist-io
   ```

2. **Open the application:**
   Simply double-click `index.html` or open it with Live Server in VS Code.
